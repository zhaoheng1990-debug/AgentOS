## Phase Gates

### G0 Baseline integrity

- Full experiment test suite passes with a workspace-local pytest base directory.
- CUDA and all three local small models are available.
- Existing v0.15 reference and analysis hashes validate before reuse.

Failure action: stop without model inference.

### G1 Grammar-backed transport

- Every semantic choice is made by the Provider among a finite registered option set.
- The Harness owns syntax and mechanically lifts the selected option into the canonical receipt.
- No hidden reference value is present in model prompts or option ordering.
- Strict receipt coverage is at least 95 percent overall and 90 percent per model.

Failure action: stop after calibration; do not create a fresh semantic run.

### G2 Calibration viability

- The burned v0.15 set is used only to estimate a model-to-role capability assignment.
- Object-plus-basis accuracy is at least 0.30 and pragmatic-preference accuracy is at least 0.40.
- Completeness is reported but cannot gate because the v0.15 reference is degenerate on that axis.

Failure action: freeze the negative result and do not invoke a coordinator.

Post-calibration object revision, recorded before any fresh holdout inference:
- The pooled gate is preserved and reported because it measures interchangeability of all models across all roles.
- The experiment's actual specialization object is the one-to-one calibration-selected routing, so a separate routed gate applies the same 0.30 object and 0.40 pragmatic thresholds to the selected role owners.
- This revision changes the aggregation object, not the thresholds. Fresh collection is exploratory until an external panel evaluates the frozen arm.

### G3 Fresh blind collection

- A new 24-object holdout is hashed before inference and contains no semantic labels.
- Three fixed role identities are context-isolated and use the calibration-selected one-to-one model assignment.
- All role outputs are frozen before any external panel label is ingested.

Failure action: retain partial receipts and prepare a recovery manifest; do not run the coordinator.

### G4 Coordinator eligibility

- Fresh role receipt coverage is at least 95 percent.
- No receipt violates role/action capability boundaries.
- A single-model baseline and a role-informed coordinator use the same public object surface.
- DeepSeek receives role receipts only in the coordinator arm and never sees external labels.

Failure action: freeze the baseline arm only, or stop entirely if the common surface cannot be preserved.
