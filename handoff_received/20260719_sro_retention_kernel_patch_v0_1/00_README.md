## Outcome

This package converts the retention/SFI theory series through v1.8 into a
bounded AgentOS CoreSlim kernel patch.

It adds:

- reference-only `SerialSelectionWitness` lifecycle;
- calibrated query-time `GradedSROCompatibilityGate`;
- six routes: direct reuse, local reconstruction, observe, reject, revise and abstain;
- append-only `DelayedRetrievalLedger` with pre-outcome sealing and hash chaining;
- Provider cognition operation `graded_sro_retention_candidate_routing`;
- public kernel exports, documentation and regression tests.

## Important separation

```text
ConstraintAlignedRetentionGate
  = should this candidate enter project-scoped retained storage?

GradedSROCompatibilityGate
  = how may an already retained witness apply to this later task?
```

The existing storage gate is unchanged. The new query-time gate does not write
memory or authorize production use.
