# Series Theory Reanalysis v0.1

## Decision

The v0.64-v0.89 series does not yet test the main collective-cognition claim.
It mostly tests semantic representation and deterministic governance. The
small number of composition experiments shows anti-additive behavior, but
cannot distinguish whether the cause is missing role complementarity,
same-Provider error correlation, or a lossy coordinator.

The next research route must therefore begin with:

`ORGANIZATIONAL_IDENTIFIABILITY_BEFORE_NEW_ARCHITECTURE`

This revises the immediate route in `THEORY_RESEARCH_ROADMAP_V0_1.md`. A new
synthetic organization should not be built until the existing archive has
been used to determine which organizational quantities are observable and
which remain confounded.

## 1. Revised Theory Decomposition

The series can be represented by four latent quantities:

```text
R = representation adequacy
U = unique conditional information supplied by roles
K = composition fidelity of the Runtime/coordinator
F = coordination friction and complexity cost
```

A candidate organization gain is:

```text
G_org_proxy =
    best-composed group decision gain
  - best-member decision gain
  - harmful certainty
  - lost correct decisions
  - coordination friction
```

For interpretation, this can be decomposed qualitatively as:

```text
G_org_proxy ~ U + synergy - composition loss - correlated error - F
```

This is a causal accounting model, not an assertion that each term has already
been identified in bits.

## 2. What the Series Actually Identified

| Quantity | Evidence from series | Current status |
| --- | --- | --- |
| `R` representation adequacy | Stable IDs, immutable surfaces, coordinate projection, atomization, and ternary absence each produced local gains. | Partially identified and task-dependent. |
| `U` unique role information | No round froze a matched best-member ablation that separates unique information from extra tokens and shared priors. | Unidentified. |
| `K` composition fidelity | v0.66, v0.82, v0.88, and v0.89 show that valid local judgments can be ignored, made unreachable, amplified, or compiled with the wrong relation. | Negative evidence; mechanism not isolated. |
| Correlated error | Sequential roles often used the same Provider and inherited prior framing. v0.88 amplified upstream groups; v0.89 produced conservative agreement. | Plausible, not directly measured. |
| `F` friction | Multiple rounds doubled or tripled token cost; v0.85 reached 91,810 tokens for two harmful mutations. | Measured operationally, not normalized against unique gain. |
| Safety suppression | v0.89 removed harm through failure closure while destroying correct action. | Clearly separated from cognition. |
| Problem/object quality | Repeated bottleneck migration from relation to admission to warrant suggests wrong-level objects. | Strong model inference, not a direct test. |

## 3. Cross-Round Invariants

### Invariant 1: local representation gains are real but narrow

Stable identity, source-surface binding, deterministic projection, minimal
semantic facts, and ternary absence all fixed named local failures. These
results should not be discarded.

They did not yield stable end-to-end transfer. The correct theory statement is
therefore conditional:

> Better representation raises the ceiling of composition, but does not imply
> positive organizational gain.

### Invariant 2: failure repeatedly migrates across object boundaries

The active bottleneck moved:

```text
evidence hygiene
-> semantic coordinates
-> relation identity
-> source grounding
-> admission state
-> context utility
-> study structure
-> semantic warrant
-> role composition
```

This pattern is unlikely to be explained by one missing enum. It is evidence
that the project repeatedly optimized a local observable while the
ontology-level cognitive object remained under-specified.

### Invariant 3: deterministic composition helps only when relations are valid

v0.67 and v0.72 support deterministic Runtime authority. v0.89 shows the
boundary: a polarity-blind rule can deterministically destroy cognition.

The refined principle is:

> Runtime must own final composition, but ownership does not guarantee
> correctness. Its meta-rules require theory-level relational semantics.

### Invariant 4: more roles did not establish cognitive multiplication

v0.88 added a second semantic role and increased harm. v0.89 added binding and
challenge roles and became a universal rejector. These are negative results
for the tested compositions, not evidence that all multi-agent organization
fails.

The missing variable is unique conditional contribution. The experiments
counted stages and receipts, but did not estimate:

```text
Delta_i = performance(group) - performance(group without role i)
```

under matched evidence, matched token budget, and preserved correct actions.

### Invariant 5: measurement objects changed during the series

Evidence F1, internal rationale F1, official rationale F1, typed
evidence/context/reject labels, harmful candidates, and abstention were used
at different times. They answer different questions.

This makes a single monotonic "v0.64 -> v0.89 progress" curve theoretically
invalid. The series is a set of experiments at different levels, not one
scalar optimization trajectory.

## 5. Theory Phase Transitions

The version line contains four distinct research regimes:

| Regime | Rounds | Actual object | Transition signal |
| --- | --- | --- | --- |
| Transfer pipeline | v0.64-v0.65 | whether staged evidence work survives fresh gates | evidence gain diverged from decision gain |
| Relational representation | v0.66-v0.75 | how claims, relations, surfaces, and states are represented | calibration success failed before transfer |
| Admission ontology | v0.76-v0.85 | evidence/context/reject and study-level utility | local modules worked while composition failed |
| Role composition | v0.86-v0.89 | factorized warrants and multi-role judgment | decomposition increased harm or suppression |

The key theoretical phase transition occurs at v0.86, not because its code is
successful, but because the research object moves from one admission receipt
to non-equivalent cognitive functions.

The second transition occurs at v0.88: the experiment begins to test
composition. That transition was not recognized strongly enough, so failures
were still answered with another role in v0.89.

## 6. Revised Collective-Cognition Claim

The earlier implicit claim was:

> More explicit cognitive stages can increase Cbit.

The series supports only the weaker statement:

> More explicit stages can improve a bounded representation subproblem.

The next theory must test:

> Multiple cognitively distinct roles produce unique, complementary
> information that a Runtime can compose into higher net decision gain than
> the best member under matched access and cost.

This claim contains three independently falsifiable requirements:

1. **Role distinction:** at least one role has positive unique conditional
   contribution.
2. **Composition:** the Runtime retains that contribution instead of
   amplifying shared error or suppressing correct action.
3. **Net gain:** the composed gain exceeds harm and friction on fresh objects.

## 7. Revised Next Research Route

### R1: Archived Organizational Identifiability Audit

Use zero Provider calls and no new architecture.

Analyze matched arms already present in:

- v0.65: one-pass versus staged evidence work;
- v0.82: frozen A14 versus A14+A16;
- v0.84: A14+A16 versus A14+A16+A18;
- v0.88: direct warrant versus EvidenceSet+ClaimScope;
- v0.89: frozen scope versus binding+challenge veto.

For each role or stage, compute:

- unique valid corrections;
- introduced errors;
- retained-correct decisions;
- action suppression;
- marginal token cost;
- oracle-union ceiling where outputs permit it;
- actual composition loss relative to that ceiling;
- error overlap and conditional error correlation where case-level receipts
  permit it.

The audit first asks whether the existing data can identify `U`, `K`, and
correlated error. Missing coordinates must be reported as
`NOT_IDENTIFIABLE`, not filled by inference.

### R2: Freeze the Organization Theory Packet

Only after R1, freeze:

- the formal definition of a cognitively distinct role;
- matched evidence and matched cost controls;
- coordinator conservation requirements;
- correction-versus-suppression metrics;
- rival models and predicted signatures.

### R3: Minimal Synthetic Phase Diagram

Construct controlled agents only for quantities R1 could not identify:

- independent versus correlated evidence;
- complementary versus redundant roles;
- conserving versus lossy coordinator;
- fixed-round versus marginal-Cbit stopping.

The synthetic test should map the region in which collaboration changes from
anti-additive to positive.

### R4: Provider Adequacy

Provider calls become appropriate only after the role variables and expected
signatures are frozen. This stage tests whether available models instantiate
the theory variables, not whether another prompt happens to improve a score.

### R5: Fresh External Benchmark

Compare best member, matched-token single iteration, independent roles,
coordinated roles, and suppression-only control. No architecture promotion
precedes this stage.

## 8. Explicitly Rejected Immediate Moves

- v0.90 polarity replay as the next main research step;
- adding another reviewer, challenger, or receipt field;
- consuming a new holdout before organizational quantities are identifiable;
- treating v0.82 local corrections as proof of group cognition;
- treating v0.89 harm reduction as cognitive gain;
- building the final AgentOS role registry before role distinctness is
  theoretically defined.

## 9. Route Decision

The highest expected theoretical Cbit now comes from R1:

`ARCHIVED_ORGANIZATIONAL_IDENTIFIABILITY_AUDIT`

It is cheaper than a new Provider experiment, directly tests whether the
existing archive can support the collective-cognition theory, and tells us
which variables genuinely require a new experiment.
